# Corporate Flow — MVP

Внутренний прототип согласования платежей и договоров на Python + Streamlit + SQLite.

## Что включено
- Вход по учётным данным из конфигурации (SHA-256-хеши паролей).
- Роли и базовые ограничения видимости заявок.
- Создание заявки: контрагент, сумма, валюта, срок, тип и цель расхода, контакты, номер договора, вложение.
- Реестр заявок, поиск и фильтр по статусу.
- Переходы статусов по ролям.
- Фиксация событий и смены статусов в журнале действий.
- Ограничение типов и размера загружаемых файлов.

## Запуск локально
1. Установите Python 3.11 или новее.
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Создайте `.streamlit/secrets.toml` по шаблону `secrets.example.toml`.
4. Сгенерируйте SHA-256-хеш пароля:
   ```bash
   python -c "import hashlib; print(hashlib.sha256('ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ'.encode()).hexdigest())"
   ```
   Вставьте хеш в `password_sha256`. Не храните пароль в открытом виде.
5. Запустите:
   ```bash
   streamlit run app.py
   ```

## Важные ограничения прототипа
Это стартовый MVP для проверки бизнес-процесса, а не готовая система для обработки реальных финансовых документов. Перед эксплуатацией необходимо:
- заменить SQLite на PostgreSQL и добавить миграции, резервное копирование и мониторинг;
- внедрить корпоративный SSO/MFA, управление сессиями, ограничение попыток входа и защиту от CSRF/атак на уровне reverse proxy;
- хранить файлы в закрытом объектном хранилище с шифрованием и отдельным сервисом авторизованной выдачи;
- проверять файлы антивирусом, а при необходимости — CDR/санитизацией документов;
- добавить TLS, управление секретами, журналирование без чувствительных данных, политики хранения и удаления;
- провести независимый аудит безопасности и тестирование прав доступа;
- формализовать маршруты согласования, лимиты, делегирование и разделение полномочий;
- пересмотреть права доступа под реальные оргструктуру и требования законодательства/ИБ.

Текущий пример сохраняет файлы локально в `private_uploads` и ограничивает доступ к заявкам базовыми правилами приложения. Не выставляйте приложение напрямую в интернет и не загружайте реальные корпоративные документы до прохождения проверки безопасности.
